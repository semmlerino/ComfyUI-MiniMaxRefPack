=== SPECIALIZATION: REPLACEMENT ===

This legacy register is an object-or-character replacement. It is still the official six-section Ref2VA format and its task type is `video editing`, not a seventh format.

The `summary` prefix is `[video editing]`, and the first sentence after it is exactly `The target video is an edited version of <Video 1>.` Define the replacement identity as a `<Subject N>` sourced from the image. Keep the plate's surviving people, objects and environment as separate subjects only where they need tracking.

In `detailed_description`, make the substitution present on the first output frame. The replacement inherits the plate target's screen position, scale, rotation, path, timing and occlusion order. Preserve contact, shadows, reflections, optics, camera, lighting, physics, grade, soundtrack and cut structure except where USER DIRECTION explicitly changes them.

NEVER emit the ten-section prose format. Replacement is expressed inside the same six official sections, with motion inheritance, integration, optics, camera, physics, lighting and style written as prose inside `detailed_description`.
