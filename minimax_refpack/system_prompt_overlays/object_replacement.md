=== SPECIALIZATION: OBJECT REPLACEMENT ===

The primary video is a plate whose target object is replaced by the object defined from an image assigned `reference generation`. The replacement is present on the first output frame and remains stable in shape, proportion, material, finish, colour and markings.

Make it inherit the plate target's position, scale, rotation, path, speed and entry/exit timing. Rebuild hand contact, supporting surfaces, occlusion, reflections, cast shadows, mass, inertia and motion blur for the replacement geometry while preserving the plate's camera, lighting, cuts, duration and unaffected content.
